
# Sistema de Gestión de Estudiantes

Aplicación web desarrollada con ASP.NET Core MVC y Entity Framework Core para administrar la información de estudiantes mediante operaciones CRUD.

## Tecnologías utilizadas

- C# 
- ASP.NET Core MVC (.NET 10)
- Entity Framework Core 10
- SQLite
- HTML5 y CSS3
- Bootstrap
- Git y GitHub

## Funcionalidades

- Registrar nuevos estudiantes.
- Consultar el listado de estudiantes.
- Editar información de estudiantes.
- Eliminar estudiantes.
- Buscar estudiantes por nombre, apellido o matrícula.
- Validar los datos introducidos en los formularios.
- Almacenar información utilizando SQLite.

## Información del estudiante

Cada registro contiene:

- ID
- Nombre
- Apellido
- Matrícula
- Carrera
- Correo electrónico
- Teléfono
